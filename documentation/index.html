NewsDesk AI

An AI newsroom for WordPress that refuses to publish what it cannot verify. Built by EtehadWP.

What this plugin does

Most AI content plugins exist to produce as much text as possible, as quickly as possible. NewsDesk AI is built on the opposite premise: the expensive mistake in publishing is not slow output, it is wrong output.

It watches the sources you choose, works out what is genuinely new, checks the factual claims against independent evidence, audits the finished article against fifteen quality axes, and hands you a sourced draft. If a story does not clear the bar, it tells you why and writes nothing.

It never publishes on its own. Auto-publish is hard-coded off and is not exposed as a setting. Every output is post_status = draft, waiting for a human.

What makes it different

  • It can decide not to write. Relevance and trust gates run before any AI cost is incurred. If nothing clears the bar in 24 hours it widens to 7 days; if still nothing, it reports NO NEWS rather than inventing a story.
  • Every claim is fact-checked and labelled VERIFIED / PARTIALLY VERIFIED / UNVERIFIED / CONTRADICTED / REJECTED, each with a risk level and a mandated action.
  • A 15-axis audit can block the draft. Six axes are blocking: missing title, missing body, ungrounded claims, fabricated references, absent sources, leftover placeholders. A critical failure means no draft is created at all.
  • It knows what you already published and decides NEW / UPDATE / REWRITE / MERGE / CORRECT / REPLACE / NO ARTICLE instead of cannibalising your own rankings.
  • Security facts are never guessed. CVE IDs, CVSS scores and affected versions are extracted by deterministic pattern matching, not by a model.

Requirements

WordPress6.5 or newer
PHP7.4 or newer (tested through 8.4)
PHP extensionssimplexml, mbstring, json. sodium or openssl strongly recommended — without one, API keys are stored unencrypted and the plugin warns you.
Outbound HTTPRequired. The plugin fetches feeds and calls AI providers. Shared hosts sometimes block this.
AI provider keyOne of OpenAI, Google Gemini, GapGPT, or any OpenAI-compatible endpoint. Not included — you supply your own.
Action SchedulerOptional but recommended. Without it jobs fall back to single-event WP-Cron, which is slower and depends on site traffic.

Installation

  1. In WordPress go to Plugins → Add New → Upload Plugin.
  2. Choose newsdesk-ai-1.0.1.zip and click Install Now.
  3. Click Activate.
  4. A new NewsDesk AI menu appears in the admin sidebar.

Installing by FTP works too — unzip into wp-content/plugins/ and activate. Database tables are created on activation and reconciled on every admin page load, so automatic, bulk and FTP updates all apply schema changes correctly.

First run in 10 minutes

The plugin is deliberately conservative, so a brand-new install will usually produce nothing on its first run. That is correct behaviour, not a fault. Work through this list.

1. Add at least three sources on one topic

NewsDesk AI → Sources → Add source. Story scoring weights multi-source corroboration heavily. With a single source, almost nothing reaches the selection threshold — by design.

2. Enter an API key

Settings → API keys. Save a key, then press Test AI connection and confirm it goes green.

3. Turn on Quick-start mode

Settings → Quick-start mode. This temporarily lowers the selection threshold to 35, trust to 20 and the content gate to 70 so you can see a first result. Your saved values are left untouched. Turn it off once you have enough sources.

4. Run it

System health → Run now. This executes the job inside the request, so it does not depend on cron. Allow two to five minutes.

5. Review

Draft review. Each generated article waits for your decision, beside its evidence map.

If nothing appears: the System health page names the first blocker explicitly — no sources, no API key, dead cron, PHP timeout, exhausted token budget. Start there rather than guessing.

Sources & trust tiers

Each source has a type and a trust tier, and both feed into scoring and fact-check weighting.

Source typeMeaning
PRIMARYThe organisation the news is about — vendor blogs, official releases.
TECHNICALDeveloper documentation, changelogs, issue trackers.
MEDIANews publications reporting on others. The default.
COMMUNITYForums, aggregators, social posts.
SECURITYAdvisories and vulnerability databases. Feeds CVE extraction.
TierMeaningDefault base trust
1Official / authoritative95
2Established publication80
3General media (default)60
4Unverified / community35

Leave Base trust blank to inherit the tier default; enter a number to override it.

Source formats

RSS and Atom take a standard feed URL. Web takes the URL of a listing page — your home page or a section — and discovers article links automatically, parsing each one via JSON-LD, then OpenGraph, then heuristics. If a site defeats automatic detection, fill in the per-source CSS selectors.

Every fetch is SSRF-hardened: redirects are revalidated hop by hop, private and link-local ranges are refused, decimal and hexadecimal IP obfuscation is detected, and responses are capped at 2 MB.

How the pipeline decides

Discovery → normalization → deduplication → clustering → scoring → editorial selection → research → evidence → fact-check → claim risk → drafting → SEO → linking → quality gate → 15-axis audit → image plan → draft.

Scoring

Stories are scored on freshness, source trust, impact, relevance, search value, actionability and uniqueness, plus a search-visibility axis. Only stories above your configured gate proceed.

The news window ladder

The first pass considers the last 24 hours. If nothing qualifies, it widens to 7 days. If still nothing, the outcome is NO NEWS and no content is created. The ladder only descends on zero items — it never widens just to find something weaker.

Cannibalization

Before writing, each story is compared against your published posts.

DecisionWhat happens
NEWA fresh draft.
UPDATE / REWRITE / MERGE / REPLACE A revision draft linked to the existing post. Nothing live is touched.
CORRECTA correction is staged against the published article.
NO ARTICLENothing is written. Writing again would compete with you.

Reviewing a draft

Draft review shows the article beside its evidence, claim by claim.

  • Status — the fact-check verdict for that claim.
  • Risk / action — how damaging an error would be, and what the system decided to do about it: keep, attribute, mark uncertain, research further, remove.
  • In body — whether the claim actually made it into the text.
  • Security intelligence — on security stories: severity, CVSS, CVE links, affected and fixed versions, exploitation status, vendor advisory.

Approving marks the version publishable. The final publish always happens in the WordPress editor, by you.

Corrections

When a new source contradicts something you already published, NewsDesk AI stages a correction and appends a dated, marked correction notice to the live post. This is the only operation in the whole plugin that modifies published content, and it adds rather than rewrites — the record of what you originally said stays intact.

Corrections are refused, with a named reason, when there is no target article, the target is not published, or there is no contradiction detail to cite.

AI providers & keys

Supported: OpenAI, Google Gemini, GapGPT, and any OpenAI-compatible endpoint. Configure an ordered list; if the first provider fails with a retryable error the next is tried. Authentication and budget errors never trigger a fallback — retrying those just burns money.

Keys are never displayed, logged or exported. They are encrypted at rest with a key derived from your WordPress salts, and eleven redaction patterns are applied to all logging. Leave the field blank to keep the stored value; tick Delete key to clear it.

Discovery, deduplication, scoring and editorial selection all run without AI. Only research and drafting call a provider — so you are not paying for stories that never clear the gate.

Images

By default the plugin produces an image plan: aspect ratio, minimum width, alt text, caption, three visual concepts, stock search terms, things to avoid, and a licensing note. The editor chooses the actual image. Generation is opt-in, and an image failure never fails the article.

SEO integration

NewsDesk AI always writes its own SEO meta. It additionally detects Yoast SEO and Rank Math and populates their fields through their documented meta keys, with no-clobber protection: a value you set by hand is never overwritten.

All in One SEO 4.x stores per-post data in its own custom tables rather than post meta, with no documented write contract. Rather than guess at another plugin's internals, the AIOSEO adapter stays inactive. Your own meta is still written and remains usable.

Scheduling

A 15-minute WP-Cron tick triggers the pipeline at your configured slots (default 00:00, 04:00, 08:00, 12:00, 16:00, 20:00, in the site time zone). The tick is only a trigger — the heavy work runs in the background through Action Scheduler.

WP-Cron on a low-traffic site is unreliable. For production, add a real system cron:

*/5 * * * * wget -q -O /dev/null https://example.com/wp-cron.php?doing_wp_cron

and set define( 'DISABLE_WP_CRON', true ); in wp-config.php.

Hooks & filters

HookTypePurpose

newsdesk_security_markersfilterPhrases that mark an item as security-related. Ships English and Persian.
newsdesk_claim_risk_markersfilterRisk markers per level. Receives the level as a second argument.

Publishing in another language? Extend the keyword lists so risk detection works:

add_filter( 'newsdesk_security_markers', function ( $markers ) {
    $markers[] = 'sicherheitslücke';   // German
    $markers[] = 'schwachstelle';
    return $markers;
} );

add_filter( 'newsdesk_claim_risk_markers', function ( $markers, $level ) {
    if ( 'critical' === $level ) {
        $markers[] = 'sicherheitsupdate';
    }
    return $markers;
}, 10, 2 );

Translating

The interface is English and fully internationalised; a Persian translation ships in languages/. To add a language, load languages/newsdesk-ai.pot in Poedit, translate, and save as newsdesk-ai-{locale}.mo in the same folder — for example newsdesk-ai-de_DE.mo.

Right-to-left locales are handled automatically through the WordPress rtl body class. The language of generated articles is a separate setting from the interface language — set it under Settings → Content.

Data & uninstall

The plugin creates 17 tables prefixed {wp_prefix}newsdesk_, plus a small number of options.

Uninstalling keeps everything by default. Data is removed only if you explicitly enable Delete all data on uninstall in Settings before deleting the plugin. Deactivating never deletes anything.

Retention is configurable per record type; 0 means keep forever, and records attached to a story are never pruned.

Troubleshooting

Nothing is generated

Expected on a new install. Check System health — it names the first blocker. The usual causes are too few sources, no API key, or dead cron.

"Stories exist but none were selected"

Your thresholds are above what the sources can reach. Lower the selection gate, or add more sources covering the same topic so corroboration raises the score.

Every run ends NO_PUBLISHABLE_STORY_FOUND

Also normal on quiet days. The plugin is allowed to produce nothing. If it never produces anything, look at STORY_NOT_ELIGIBLE in the logs.

Jobs stay queued and never start

WP-Cron is not firing. Install Action Scheduler, add a real system cron, or use Run now while you sort it out.

Job stuck mid-phase for over an hour

PHP almost certainly timed out. Raise max_execution_time to at least 300, and retry from the dashboard. A full run normally takes two to five minutes.

SCHEMA_FAIL / SCHEMA_RETRY in the logs

The model's JSON did not match the required shape. The Details column names the exact field. Usually the model is too weak or lacks JSON mode — switch to a stronger one.

Feeds work in a browser but fail here

Your host has probably blocked outbound HTTP, or the feed resolves to a private IP and the SSRF guard refused it.
